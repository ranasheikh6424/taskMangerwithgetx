## 🌟 **Task Manager App**  

A **Flutter-based Task Manager** application to help users organize and track their daily tasks efficiently. 🚀  

![Flutter](https://img.shields.io/badge/Flutter-Framework-blue) ![Dart](https://img.shields.io/badge/Dart-Language-blue) ![Firebase](https://img.shields.io/badge/Firebase-Backend-yellow)  

---

### 📌 **Features**  
✅ Create, Edit & Delete Tasks  
✅ Organize Tasks with Categories  
✅ Set Task Priorities & Deadlines  
✅ Firebase Integration for Real-time Sync  
✅ Responsive UI & Dark Mode  

---

### 🛠 **Getting Started**  

#### **1️⃣ Prerequisites**  
Make sure you have the following installed:  
- Flutter SDK: [Download Here](https://flutter.dev/docs/get-started/install)  
- Dart SDK  
- Android Studio or Visual Studio Code  
- Firebase (if using Firestore for data storage)  

#### **2️⃣ Clone the Repository**  
```bash
git clone https://github.com/ranasheikh6424/taskMangerwithgetx.git
cd taskMangerwithgetx
```

#### **3️⃣ Install Dependencies**  
```bash
flutter pub get
```

#### **4️⃣ Run the Application**  
```bash
flutter run
```
